# Plain Craft Launcher 2 (PCL2) 纯净可安装程序备份与分发

本仓库/项目提供 **Plain Craft Launcher 2 (PCL2)** 经典版本的归档备份与独立 Windows 安装程序，旨在长期保存并方便广大玩家直接下载使用。

---

## 📌 版本信息

- **软件名称**：Plain Craft Launcher 2 (PCL2)
- **启动器版本**：**正式版 2.13.1.1** (内部版本号：408)
- **打包安装程序**：`PCL2_Setup.exe` (单文件原生 GUI 安装向导，约 2.72 MB)
- **运行环境要求**：Windows 10 / 11 (支持 .NET Framework 4.5+，Windows 系统均已内置)

---

## 🚀 核心特性与安全保障

### 1. 彻底脱敏与隐私安全
- **零个人信息残留**：在打包过程中，严格排除了原机所有历史启动脚本（如 `LatestLaunch.bat`）、运行时日志（`Log*.txt`）、本地账户数据库及微软正版 OAuth Token。
- **全新空白初始化**：任何人下载安装后均为初始未登录状态，不会携带或泄露任何个人账号凭据。

### 2. 内置防自动更新（Anti-Auto-Update）
- 本安装包在解包部署时，**自动往 `PCL\Setup.ini` 中注入 `SystemSystemUpdate:3` 配置项**。
- 有效防止启动器在未经允许的情况下自动在后台拉取新版本或强制弹窗更新，保障老版本运行的绝对稳定与一致性。

### 3. 原生独立 GUI 安装向导
- **免额外依赖**：无需安装 7-Zip、Inno Setup 或任何打包框架，单文件 `.exe` 即开即装。
- **自定义路径**：默认安装至用户目录 `%LOCALAPPDATA%\Programs\PCL2`（无需管理员权限，杜绝权限提升弹窗与系统盘污染），同时支持任意自选路径。
- **快捷方式管理**：支持可选一键创建「桌面快捷方式」和「开始菜单程序项」。
- **安全校验与回滚机制**：解压全过程内置 SHA-256 完整性哈希校验，若中途取消或校验失败将自动执行安全回滚。

### 4. 规范与安全的卸载集成
- 自动注册至 Windows **「设置 -> 应用与功能（已安装应用）」** 及控制面板。
- 卸载时仅清理 PCL2 启动器自身的运行库、快捷方式与注册表，**绝对不会递归删除玩家后续下载的 Minecraft 游戏版本、存档、光影与模组（Mod）**。

## 📥 下载与安装步骤

1. 前往本仓库的 [Releases 页面](../../releases) 或从仓库中下载最新的 **`PCL2_Setup.exe`**。
2. 双击打开安装程序，根据提示选择安装目录与快捷方式选项。
3. 点击 **「Install（安装）」**，等待进度条走完。
4. 勾选「安装完成后立即启动」，点击 **「Finish（完成）」** 即可开始游戏。
